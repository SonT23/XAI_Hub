# NCKH — Explainable AI & Concept Bottleneck Models

Wiki nghiên cứu cá nhân về Explainable AI (XAI) ứng dụng trong Computer Vision, tập trung vào Concept Bottleneck Models (CBM). Gồm ghi chú kiến thức nền (Toán, Machine Learning, Deep Learning, XAI/CBM), thư viện bài báo, và từ điển thuật ngữ Anh-Việt.

**Trang web:** _điền link GitHub Pages của bạn vào đây sau khi bật xong (xem MAINTENANCE.md)_

Nguồn dữ liệu gốc là một workspace Notion cá nhân; repo này là bản đồng bộ công khai, đọc được mà không cần tài khoản Notion.

## Nội dung

- **Toán nền tảng** — Đại số tuyến tính, Giải tích, Xác suất & Thống kê
- **ML cơ bản** — Parameter, Hyperparameter, Performance Measures
- **Deep Learning** — Autoencoder, VAE, CNN, Latent Space, Transformer/ViT, CLIP
- **Explainable AI** — Tổng quan XAI, Post-hoc, Concept-based, CBM (trọng tâm), biến thể CBM, đánh giá lời giải thích, bộ dữ liệu & công cụ
- **Thư viện bài báo** — bibliography các bài báo đã/đang đọc
- **Thuật ngữ Anh - Việt** — từ điển song ngữ hơn 160 thuật ngữ
- **Kỹ năng nghiên cứu** — cách đọc bài báo khoa học, lộ trình đọc cho đề tài CBM

## Công nghệ

Site build bằng [MkDocs](https://www.mkdocs.org/) + [Material theme](https://squidfunk.github.io/mkdocs-material/), host miễn phí trên GitHub Pages, tự động build lại qua GitHub Actions mỗi khi có commit mới. Dữ liệu Glossary được đồng bộ tự động từ Notion API.
